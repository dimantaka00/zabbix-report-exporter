Panduan operasional MVP LAN internal
Dokumentasi utama: README.md
Bukti penerimaan dan hasil pengujian: docs/mvp-checklist.md
Lokasi proyek: D:\KERJAAN\zabbix-report-exporter
Lokasi disk Docker: D:\DockerDesktopWSL
Buka zabbix-report-exporter.code-workspace pada folder D di IDE.
Jalankan perintah dari folder proyek pada komputer server:
Set-Location -LiteralPath 'D:\KERJAAN\zabbix-report-exporter'

Menjalankan Aplikasi
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d

Cek status:
docker compose -f docker-compose.yml -f docker-compose.prod.yml ps

Menghentikan Aplikasi
docker compose -f docker-compose.yml -f docker-compose.prod.yml stop

Menjalankan Kembali
docker compose -f docker-compose.yml -f docker-compose.prod.yml start

Restart
docker compose -f docker-compose.yml -f docker-compose.prod.yml restart

Melihat Log
Backend:

docker compose -f docker-compose.yml -f docker-compose.prod.yml logs worker --tail=100

Frontend:

Report
Melihat report:
curl.exe -s http://localhost:5010/api/v1/reports

PDF disimpan pada:
storage/reports/

Database Backup
Backup otomatis menggunakan:
scripts/backup-db.ps1

Menjalankan manual:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\backup-db.ps1"

Backup disimpan pada:
backup/

Backup memakai arsip PostgreSQL custom (.dump) dan arsip PDF (.zip).
Backup lama tetap disimpan.
Scheduled Backup
Windows Task Scheduler:
Zabbix Report Database Backup

Jadwal:
Setiap hari pukul 02:00

Cek:
Get-ScheduledTaskInfo -TaskName "Zabbix Report Database Backup"

Backup berhasil jika:
LastTaskResult : 0

Uji Restore Database
Uji pemulihan memakai PostgreSQL sementara yang terpisah dari produksi:

powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\test-restore.ps1" -BackupFile ".\backup\NAMA_BACKUP.dump"

Script memeriksa hasil restore, lalu membersihkan container pengujian.
Pemulihan database produksi memerlukan pemeriksaan backup dan persetujuan penggantian data.
